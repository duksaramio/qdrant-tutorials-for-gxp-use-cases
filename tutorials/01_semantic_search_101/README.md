# Tutorial 01: Semantic Search 101 for GxP Quality & CSV

| Time: 15–20 min | Level: Beginner | Infrastructure: Local Qdrant (`http://localhost:6333`) + Local Ollama (`qwen3-embedding:8b`) + Langfuse (`http://localhost:3000`) |
| :--- | :--- | :--- |

## Overview

In Life Sciences and Computer System Validation (CSV / GAMP 5), Quality Assurance (QA) teams manage thousands of controlled documents (SOPs, Validation Protocols, Deviations, CAPAs, Change Controls, and Risk Assessments).

This tutorial demonstrates how to:
1. Connect to **Local Qdrant** at `http://localhost:6333` and **Local Ollama** (`qwen3-embedding:8b`, 4096 dimensions).
2. Trace vector embedding generation and semantic retrieval spans with **Langfuse Observability** at `http://localhost:3000`.
3. Create a collection with 4096-dimensional cosine distance vector parameters.
4. Ingest controlled GxP documents with rich payloads.
5. Execute natural language semantic searches and apply payload filters (`doc_type`, `effective_year`, `system`).

---

## 🔍 Observability with Langfuse

Every vector operation in this tutorial is automatically traced in Langfuse:
- **`@observe(as_type="embedding")`**: Traces dense embeddings generated by local Ollama (`qwen3-embedding:8b`), logging token counts and dimension sizes.
- **`@observe(as_type="span")`**: Traces the Qdrant document ingestion and point uploading phase.
- **`@observe(as_type="retriever")`**: Traces similarity search queries, active filters, and returned candidate documents with similarity scores.

Open the Langfuse dashboard at `http://localhost:3000` to inspect query traces, latency, and retrieval quality.
